# Security

This workspace has no supported production release. Its admission and
authentication APIs have the [trust boundaries](docs/design.md#trust-boundaries)
described in the design document. Content preparation remains unavailable.

Report suspected vulnerabilities privately. Use GitHub's **Report a
vulnerability** option if it is available for this repository. Otherwise, ask a
repository maintainer for a private reporting channel without posting exploit
details publicly. Include the affected revision, feature configuration,
reproduction steps, and expected and observed behavior. Redact keys, credentials,
tenant data, and sensitive attestation evidence.
